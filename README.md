# Hariom Studio — Landing Page Showcase

A standalone, responsive landing page built to showcase creative directions for digital products, commerce brands, and service businesses.

## Design direction

- Dark editorial canvas with acid-lime accents and oversized typography
- CSS-built product mockup and three distinct visual concept studies
- Responsive navigation, project category filters, subtle scroll reveals
- Clear service narrative, process section, and contact calls to action
- Search/social metadata, semantic HTML, keyboard-accessible menu, reduced-motion support
- No framework or build step required

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Edit copy, links and sections in `index.html`
- Update colors, layout and breakpoints in `styles.css`
- Update navigation, category filters and progressive enhancement in `script.js`
- Replace concept studies with real client work only when you have permission and accurate project details.

## Important

The three showcase panels are original concept studies, not claimed client projects or performance case studies. Replace the contact email and social links if you deploy this for another business.

## Deploy

This is a static site and can be hosted on GitHub Pages, Cloudflare Pages, or any static web host. For Cloudflare Pages, use the repository root as the build output directory; no build command is needed.
